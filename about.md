# KBOT

Small bot mod for practicing levels. You get a row of buttons at the top of the screen while you're playing: Off, Rec, Play, Auto and Save.

Hit **Rec** and play, and it writes down every click. **Save** puts the macro in a file, and **Play** runs it back. **Auto** is a bare-bones auto-player that jumps when it sees a spike coming up. It only knows how to do cube, so don't expect it to beat anything hard on its own.

Heads up, replays can fall out of sync since GD's physics depends on frame timing. If a run goes off the rails halfway through, that's probably why.

It doesn't block the game from submitting a completion, so keep it off levels you're trying to get on a leaderboard or list.
