<h1 align="center">KBot</h1>

<p align="center">
  A practice and offline tool for Geometry Dash, built with <a href="https://geode-sdk.org">Geode</a>.
</p>

---

## Features

- **Record**: records your inputs as you play, step by step
- **Replay**: plays a saved macro back
- **Auto**: a basic auto-player that jumps over hazards in cube sections
- **Save**: writes your macro to a file so you can load it again later

Buttons for all of these appear along the top of the screen while you are in a level.

## Installation

1. Install [Geode](https://geode-sdk.org) for Geometry Dash.
2. Download the latest `.geode` file for your platform.
3. Place it in the `geode/mods` folder inside your Geometry Dash directory.
4. Launch the game. KBot will show up in the Geode mods list.

## How to use

1. Open a level (practice mode works well).
2. Press **Rec** and play. Your inputs are recorded.
3. Press **Save** to write the macro to a file.
4. Press **Play** to replay it.
5. Press **Auto** to let the simple auto-player try the level.
6. Press **Off** to turn the bot off.
