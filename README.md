# KBot

A practice and tool for Geometry Dash.

## Features
- **Record:** record your inputs as you play
- **Replay:** play a saved macro back
- **Auto:** a basic auto-player that jumps over hazards in cube sections
- **Save:** save macros to a file so you can reload them later

Buttons for all of these appear at the top of the screen while you're in a level.

## Notes
- The auto-player is simple and works best on straightforward cube sections
- Replays can drift out of sync, since the game's physics depends on frame timing
- Intended for practice, offline play and videos. Don't submit botted runs to leaderboards.
